# Koa

## Introduction:
Play as a robot diver named Koa in this 2D perspective 3D platformer! Explore a mysterious underground cavern littered with ancient unknown technology and simple puzzles. Use Koa’s light to reveal hidden objects, and use them to reach your goal!
